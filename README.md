# WHELP Lab

WHELP Lab at the Kansas Population Center studies women’s health. This repository connects the lab’s papers with the analysis code, documentation, and data available to reproduce their results.

## [Working Papers](working-papers/)

Browse current research and its available replication materials. Each paper folder includes a study description and instructions, with a link to a public working paper when one is available.

## [Published Papers](published-papers/)

Find the journal citation and article link in each paper’s README, alongside the replication materials and any public working paper link.

## Data and Code

Each paper folder explains how to run its code and describes the shared data. For studies that use restricted source data, the paper’s README explains how to request access and what the shared files can reproduce.
